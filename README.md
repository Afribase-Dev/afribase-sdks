# Afribase SDKs

Official client libraries for [Afribase](https://useafribase.app) — an
open-source backend-as-a-service platform. Each one wraps the same
auth, database (query builder), storage, realtime, email and edge
functions API for its language.

| SDK | Language | Install |
| --- | --- | --- |
| [`afribase-js`](./afribase-js) | JavaScript / TypeScript | `npm install @afribase/afribase-js` |
| [`afribase-py`](./afribase-py) | Python | `pip install afribase` |
| [`afribase_flutter`](./afribase_flutter) | Dart / Flutter | add to `pubspec.yaml` |

See each SDK's own README for usage.
